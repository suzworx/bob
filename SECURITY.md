# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub's security advisories: on this repository, open the
**Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the impact you expect. We aim
to acknowledge a report within a few days and will keep you updated until it is
resolved. Please give us a reasonable time to ship a fix before any public
disclosure.

## Scope

The server (`apps/api`, `apps/ai`), the web app (`apps/ui-v2`), the iPhone app
(`apps/ios`, `apps/mobile`), the Cardputer firmware (`apps/cardputer`) and the
Supabase schema, policies and functions (`supabase/`) are all in scope.
Never include real credentials, tokens, audio or personal data in a report.
